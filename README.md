# Autonomous Drone Object Tracking

This project implements autonomous object tracking using a drone with ROS2 and Aerostack2.

## Quick Start

1. Install dependencies:
   ```bash
   ./scripts/install_dependencies.sh
   ```

2. Set up environment:
   ```bash
   source ./scripts/setup_environment.sh
   ```

3. Build the project:
   ```bash
   cd as2_workspace
   colcon build
   ```
